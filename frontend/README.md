# Frontend Setup Guide

This repository contains the frontend for the project.
Follow the steps below to set up and run it locally.

---

## Get Started

### Clone the Repository

```bash
git clone github.com/aditya-sutar-45/get-me-hired-alphabyte
cd get-me-hired-alphabyte/frontend
```

### Install dependencies

```bash
npm install
```

### Run the frontend

```bash
npm run dev
```

The app will run at:
`http://localhost:5173`
